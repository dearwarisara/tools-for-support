# Support Toolkit

หน้าเว็บรวมเครื่องมือและเอกสารสำหรับทีม Support:

- [Doc to Web](https://jjjaydem.github.io/doc2web/) — แปลงไฟล์เอกสารเป็น HTML
- [PDF Prep Studio](https://dearwarisara.github.io/pdf-prep-studio/) — เตรียม PDF และปกสำหรับ presentations
- [Photoshop / Photopea](https://www.photopea.com/) — แต่งภาพออนไลน์
- [Slackemoji](https://slackmojis.com/) — ค้นหา emoji สำหรับ Slack
- [Convert Case](https://convertcase.net/) — เปลี่ยนรูปแบบตัวอักษร
- [Viewport](https://getmybrowser.com/) — ตรวจสอบข้อมูล browser และอุปกรณ์
- [Jarvis](https://jarvis.optiwise.io/wp-login.php) — ระบบภายในสำหรับจัดการงานและข้อมูลของทีม
- [Time Away](https://timeaway.optiwise.io/) — จัดการและตรวจสอบช่วงเวลาที่ไม่อยู่ของทีม
- [Resource Guru](https://app.resourceguruapp.com/hi/optiwise/schedule) — ดูตารางงานและวางแผนการใช้ทรัพยากรของทีม
- [Ticket Tracking](https://docs.superhuman.com/d/Ticket-Tracking_djFHSGxCo4I/Ticket-Journal_suEtqXoz#_lu1OSNrj) — เปิดดู Ticket Journal และติดตามรายละเอียดของ ticket
- [Ticket Overwatch](https://ticket-overwatch.optiwise.io/) — ติดตาม ticket ของทีม Support
- [Financial Highlights/ Major Shareholders](https://www.dropbox.com/work/09%20Support/Program) — เครื่องมืออัปเดตข้อมูล Financial Highlights ผ่าน Dropbox

## เครื่องมือและเอกสารที่เปิดล่าสุด

แสดง 3 รายการที่เปิดล่าสุด โดยรวมทั้งเครื่องมือและเอกสาร เรียงตามเวลาเปิดพร้อมระบุประเภทและเวลา ประวัติบันทึกแยกในเบราว์เซอร์ของแต่ละคน และล้างได้ด้วยปุ่ม “ล้างประวัติ”

## เปิดใช้งานในเครื่อง

เปิด `index.html` ได้โดยตรงในเบราว์เซอร์ หรือใช้ static server เช่น:

```bash
python -m http.server 8000
```

จากนั้นเปิด <http://localhost:8000>

## GitHub Pages

โปรเจกต์นี้เป็น static site ไม่มีขั้นตอน build สามารถตั้งค่า GitHub Pages ให้ deploy จาก branch `main` และ folder `/ (root)` ได้เลย
