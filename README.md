## โหมดสว่างและโหมดมืด

กดปุ่มสลับธีมที่มุมขวาบนเพื่อเลือกโหมดสว่างหรือมืด ระบบจำค่าที่เลือกไว้ในเบราว์เซอร์ หากยังไม่เคยเลือก จะใช้ธีมตามการตั้งค่าของอุปกรณ์

## รายการโปรด

กดดาวที่การ์ดเครื่องมือหรือเอกสารเพื่อเพิ่มลงใน “รายการโปรด” ซึ่งแสดงต่อจาก Notepad กดดาวซ้ำเพื่อยกเลิกได้ รายการโปรดบันทึกแยกในเบราว์เซอร์ของแต่ละคน

## Notepad

โน้ตอยู่ก่อนรายการโปรด แทนส่วนประวัติการเปิดล่าสุด เพิ่ม แก้ไข และลบโน้ตได้ พร้อมปุ่มเลิกทำหลังลบ เลือกสีเหลือง เขียว ชมพู ม่วง ฟ้า เทา หรือเทาเข้ม รองรับธีมสว่างและมืด ข้อความและสีบันทึกอัตโนมัติในเบราว์เซอร์ของแต่ละคน ไม่ซิงก์ระหว่างคนหรืออุปกรณ์ โน้ตเริ่มต้นเรื่อง preview link แสดงสำหรับผู้ที่ยังไม่มีโน้ตบันทึกไว้

## เปิดใช้งานในเครื่อง

เปิด `index.html` ได้โดยตรงในเบราว์เซอร์ หรือใช้ static server เช่น:

```bash
python -m http.server 8000
```

จากนั้นเปิด <http://localhost:8000>

## GitHub Pages

โปรเจกต์นี้เป็น static site ไม่มีขั้นตอน build สามารถตั้งค่า GitHub Pages ให้ deploy จาก branch `main` และ folder `/ (root)` ได้เลย
